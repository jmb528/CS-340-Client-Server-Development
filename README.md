# CS-340: Client/Server Development

## Grazioso Salvare Rescue Animal Dashboard

For this project, I developed an interactive dashboard for Grazioso Salvare that uses Python and MongoDB to organize and display animal shelter data. The dashboard allows users to filter animal records based on specific rescue requirements and view the results through tables, charts, and an interactive map. The purpose of this project was to make it easier for Grazioso Salvare to identify animals that may be suitable for search-and-rescue training.

## How do you write programs that are maintainable, readable, and adaptable?

When writing programs, I try to keep my code organized, readable, and easy to modify without having to change everything else. One of the biggest things I learned from this project was the importance of separating different parts of an application. In Project One, I created a Python CRUD module that handled communication with the MongoDB database. I was then able to reuse that module in Project Two when building the dashboard instead of writing all the database operations again.

This approach made the project easier to manage and troubleshoot because the database functionality was separate from the dashboard itself. It also made the code more adaptable since changes to the database operations could be handled within the CRUD module. In the future, I could use a similar module for other applications that need to store, retrieve, update, or delete information from a database.

## How do you approach a problem as a computer scientist?

My approach to solving problems usually starts with understanding what needs to be accomplished and breaking the requirements into smaller, more manageable tasks. For the Grazioso Salvare project, I had to consider how the organization would use the database and dashboard to identify animals that met specific rescue training requirements. Rather than just focusing on making the program work, I also had to think about how the information would be presented to the user.

This project was different from some of my previous assignments because I was connecting multiple components together to create a functional application for a specific client. I had to work with MongoDB, Python, and dashboard widgets while making sure everything communicated properly. Moving forward, I would continue using a step-by-step approach, testing individual components, troubleshooting issues as they come up, and keeping the client's needs in mind throughout development.
